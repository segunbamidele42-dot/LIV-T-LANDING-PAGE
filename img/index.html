Local image folder ================== This folder is reserved for images you may want to host locally on your own domain rather than referencing from the original CDN. The current build of index.html and order-page/index.html references all images via absolute URLs from: - https://naturalwellness.gethealthyforever.club - https://goodhealth.betalife.info If you want to make the bundle fully self-contained: 1. Download all referenced images into this img/ folder 2. Update the src="https://..." paths in the HTML to relative paths (e.g. src="img/liv-t-550-bottle.png") Doing so means the page will not depend on those external CDNs staying online.
